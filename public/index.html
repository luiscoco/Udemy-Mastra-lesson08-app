    01

    Launch the real Studio

    npm run studio starts the pinned Mastra CLI on port 4208. The host, agents, workflow and telemetry are actual SDK components.

    02

    Record native execution evidence

    A registered two-step workflow creates a trace. The app flushes the native exporter and checks the persisted trace instead of manufacturing a timeline.

    03

    Inspect the lifecycle

    Follow validated input, lookup, formatting and the final task result. Traces describe observed execution rather than guaranteed access to hidden reasoning.

    04

    Separate two outcome levels

    The SDK can complete a workflow whose business result reports a missing lesson. Inspect the task contract as well as runtime success.

    05

    Use bounded local storage

    Trace data is written to this app's ignored .mastra directory. Metrics aggregation and external telemetry export are not configured.

    06

    Diagnose before editing

    Locate whether the issue is input, registration, a tool, a workflow step or provider access. Change the relevant boundary and rerun the same task.
